## Findings
1. **`open_checkout` works (D18 confirmed).** The page navigated the tab. The extension followed, dropped our tools and picked up Stripe's tools in the same conversation, with no human help. The `null` tool result did not confuse the model.
2. **Stripe exposes its tools from a subframe** (`_401_`). On first load it offered 3 tools. Per its own description, `fill_payment_form` should be used after `select_payment_method`.
3. **The agent never received `fill_payment_form`.** The user saw it in **DevTools → Application → WebMCP**, but **not in the side panel**. Across 6 model requests over about an hour, the extension sent the same 3 tools every time.
   - Likely cause (from the extension source, commit `051a93c`): the top-frame content script re-lists tools only when the **top document's** `ontoolchange` fires (`content.ts`). Reports from subframes are discarded (`useActiveTabTools.ts`: `if (sender?.frameId && sender.frameId !== 0) return;`).
   - So a tool that a cross-origin **subframe** registers later doesn't reach the side panel, unless the top frame's `toolchange` fires or a full re-list happens.
   - It is also possible that `fill_payment_form` isn't visible to the top frame's `getTools()` at all (for example, a different frame or `exposedTo` setting). DevTools shows every frame. **Not yet distinguished.**
4. **Confirmation behaviour (Q4):**
   - Before being told, the model **did ask** ("Should I submit … ?"), and held off when only nudged.
   - When the user wrote "Submit the checkout form and complete the payment", the model treated it as confirmation and called `submit_payment` at once.
   - **Whether the extension showed its own permission prompt for `submit_payment` (expected for a `consequentialHint` tool) is still to be confirmed with the user.**
   - Stripe answered "Payment submission started." With empty card fields, and after the session expired, no payment resulted.
5. The extension spotlights `get_order_summary` (base64), so Stripe marks it untrusted-content. The other two Stripe results were plain.
